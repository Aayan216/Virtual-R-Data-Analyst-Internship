# Week 1 — Data Cleaning and Preliminary Analysis with R

## Objective
Clean and inspect the Telco Customer Churn dataset, perform preliminary descriptive analysis, and create exploratory visualizations using R.

## Dataset
Telco Customer Churn — 7,043 rows and 21 variables after cleaning.

## Completed Work
- Dataset loading and structure inspection
- Missing and blank value checks
- Duplicate detection and removal
- `TotalCharges` conversion to numeric
- Handling of zero-tenure blank total charges
- Column-name standardization with `janitor`
- Categorical variables converted to factors
- Descriptive statistics
- Churn and contract analysis
- Six exploratory visualizations

## Final Validation
- Rows: 7,043
- Columns: 21
- Missing values: 0
- Duplicate rows: 0

## Key Finding
Month-to-month customers had the highest churn rate (42.71%), compared with 11.27% for one-year contracts and 2.83% for two-year contracts.
