# Virtual R Data Analyst Internship

This repository contains the work completed during my **Virtual R Data Analyst Internship**, covering practical data analysis using **R and RStudio**.

The internship work progresses from data preparation and visualization to statistical analysis, predictive modeling, and final reporting using the **Telco Customer Churn** dataset.

## Weekly Tasks

### Week 1 — Data Cleaning and Preliminary Analysis
- Data cleaning and preprocessing
- Missing-value and duplicate checks
- Descriptive statistics
- Preliminary churn analysis

### Week 2 — Data Visualization and Insight Communication
- Exploratory data analysis
- Customer churn visualizations
- Segment-level comparisons
- Data-driven insight communication

### Week 3 — Statistical Analysis and Predictive Modeling
- Hypothesis testing
- Correlation and assumption checks
- Logistic regression
- Train/test split and cross-validation
- Model performance evaluation

### Week 4 — Comprehensive Data Analysis Reporting and Presentation
- Integration of Weeks 1–3
- Detailed analytical narrative
- R code excerpts and output snapshots
- Integrated findings and practical implications
- Challenges, improvement plan, lessons learned, and future directions

## Tools & Technologies

- **Language:** R
- **IDE:** RStudio
- **Data Analysis:** tidyverse, janitor, skimr
- **Visualization:** ggplot2
- **Statistical & ML:** caret, pROC, broom, car
- **Version Control:** Git & GitHub

## Dataset

The projects use the **Telco Customer Churn** dataset to study customer behavior, identify churn-related patterns, perform statistical analysis, and build a predictive classification model.
